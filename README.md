# Choong Sze Ying – CV

Personal CV webpage. Single file (`index.html`), no build step.

## Publish with GitHub Pages
1. Create a new repository (e.g. `szeying-cv`, or `<username>.github.io` for a root URL).
2. Upload `index.html` and `README.md` to the repository's main branch.
3. Go to Settings > Pages, set Source to "Deploy from a branch", choose `main` and `/ (root)`, then Save.
4. After a minute the site is live at `https://<username>.github.io/<repo-name>/`.
